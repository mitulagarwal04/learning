# AI Engineering — 32-week plan

Start: **Thu 12 Nov 2026** · Planned end: **~24 Jun 2027** (32 weeks), with buffer up to the 8-month mark.

## Files in this folder

| File | What it is |
|---|---|
| `CURRICULUM.md` | Every topic, its depth level, and the time budget for each track |
| `ROADMAP.md` | Week-by-week plan, 6 phases, and what each week is assessed on |
| `PROGRESS.md` | Status of every week, with assessment scores. **Claude updates this after each assessment** |
| `weeks/week-NN.md` | The learning path for one week: links (videos, docs, books) in the order to use them, plus the build exercises. Written one week ahead |
| `assessments/week-NN.md` | The questions you were given, your results, and what to fix |

Code does **not** live here. It goes in two GitHub repos:
- `ai-eng-lab`: exercises and from-scratch builds (one folder per week)
- `docmind`: the capstone (a self-hosted document intelligence platform), started in week 5

## How it works

1. **Learn.** Open `weeks/week-NN.md` and work through it top to bottom: watch, read, build. No logging.
2. **Tell Claude what you completed:** the whole week, or specific blocks ("blocks 1–3 of week 2 done").
3. **Get assessed.** Expect MCQs, descriptive questions, code tasks, debugging puzzles, math by hand, and a review of your repo.
4. **Marked complete.** Pass (≈75% overall, with the code tasks working) and the week is marked done in `PROGRESS.md`. Otherwise you get a short targeted re-do on the weak spots, then a re-test on just those.

## Rules (the strict part)

- **No pass, no next week.** The plan has 3 buffer weeks for re-dos, so use them instead of skipping.
- **Type it yourself.** No copy-pasting tutorial code. Using AI to generate code you're supposed to be learning is off-limits in from-scratch exercises. Using it to *explain* things is fine.
- **Assessments are closed-book** unless a question says otherwise.
- **Benchmarks and evals get numbers.** Never write "it's faster". Write the measurement.

Rough weekly rhythm: about 4 sessions of 2h plus a few 30-minute sessions (≈9.5h). Light days suit the videos and math blocks.
